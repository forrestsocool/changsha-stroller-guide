## 采集流程

先搜“长沙 婴儿床”，再补搜“长沙 拼接床”“长沙 折叠婴儿床”“长沙 游戏床”“长沙 婴儿睡篮”等不同结构关键词。不限品牌、原价、实木、铝合金、钢架、布网、复合材料或其他材质。搜索词只是入口，不代表已找到该类型。

逐条打开详情，确认是出售整床及长沙区域，排除仅售配件、租赁、求购和异地结果；记录排除原因，不凭品牌或材质判定不合格。无法判断是否用于婴儿睡眠时保留疑问，不替卖家背书。

核对标题、价格、区域和图片属于同一个商品，复制实际详情链接与 ID。尺寸、材质、品牌、配件均为卖家自述，缺失时使用 null 或“待核实”，不可从类似品牌推断。不要记录卖家手机号、家庭门牌或其他无关个人信息。

以商品 ID 去重；重复观察保留最新记录。已失效记录保留来源，但不纳入当前床型参考与挂牌价范围。不将挂牌价称为成交价或合理估价。

## 数据格式

`data.js` 中 `cribData.listings` 是唯一商品来源。每条记录字段：

| 字段 | 含义 |
| --- | --- |
| id / url | 原详情页的数字 ID / https://www.goofish.com/item?id=实际ID，必须一致 |
| title | 商品原始标题 |
| price | 数字挂牌价，未知为 null，不能用 0 代替未知 |
| district | 详情显示的长沙区域；不确定写“长沙·区域待核实” |
| bedType | 从实物结构归纳的床型，不以品牌命名 |
| material | 卖家自述材质，未说明填“待核实” |
| brand | 卖家自述品牌或 null，无品牌也可入库 |
| dimensions / accessories / description | 尺寸、配件和描述摘录，可缺省 |
| status | observed（采集时可见）或 unavailable（确认失效） |
| observedAt | 实际观察时间，带时区的 ISO 日期时间 |
| evidence | 采集依据：在哪个搜索词、详情的哪些信息得到核实 |
| questions | 待核实事项，不能默认为已通过验货 |
| photo | null 或下述图片对象 |

图片对象包含 `url`（该商品的 HTTPS alicdn 图片地址）、`itemId`、`sourceUrl`（与记录 url 一致）、`verified: true`。只有人工看过图片且核对了原详情对应关系才能标 true。代码只能检查字段绑定，无法替代人工识别图中实物。没有可靠地址就留 null，不得复制推车图、借用同品牌图或使用生成图冒充实拍。

`collection.checkedAt` 只在完成实际采集后更新；同时修改 `collection.status` 与 `message`，说明采集范围和限制。同步更新 README 当前状态。网页计数和床型库自动从记录产生，不手工写“20张”“12款”。

## 回归验证

运行 `node --test tests/crib.test.cjs`。测试数据仅在测试文件中，不导入生产库。重点检查错图绑定、失效记录、重复 ID、未知价格、任意材质入库、筛选以及空库。
