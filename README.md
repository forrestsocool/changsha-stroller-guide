## 💡 项目背景与甄选口径

在二手市场挑选婴儿推车时，低端入门车型（新车实际成交价长期低于 ¥1000 的型号，如 D619、D628、GB101 等）因材料与耐磨度有限，承担二手老化、车轮旷量与卫生磨损并不划算。

本指南严格**剔除千元以下低端车**，锁定好孩子历史上研发成本高、车架扎实、产品力强，但**二手折价极为划算**的中高端平台：
1. **Swan 金羽系列 (GB826 / GB827 / GB828)**：高景观罕见的 7.2kg 纯碳纤维车架与 ARS 四轮万向同步转向。
2. **安全舱体系 (E5011 / ORSA Flip / E6011)**：40cm 豪华超宽座舱、单手收车与精密 8 轴承系统。
3. **ORSA 系列 (D850 / C4017)**：重量与推行最均衡的 6.8kg 黄金标杆。
4. **飞羽系列 (D5000 / 飞羽 Plus D6017)**：全碳纤维极限羽量与大角度平躺出行。
5. **蜂鸟系列 (C826 / C828 / D829)**：约 5.6kg 超轻兼顾双向推杆与新生儿平躺的高性价比神车。
6. **POCKIT 口袋车系列 (3S / 3H / 3Q / 2S)**：登机免托运与超微收折的差旅首选。

## 🚀 核心功能与页面架构

采用现代极简设计（Apple / Linear 灵感、毛玻璃磨砂效果、自适应响应式布局）：

### 🚗 Tab 1：车型参考库 (15 款中高端车型)
- **多维技术参数**：当年新车参考价、标价、整车净重、车架材质、平躺模式、双向推行、座高座宽、避震轮组、折叠尺寸与适用场景。
- **推荐档位**：
  - 🥇 **第一档 · 强烈推荐蹲**：Swan 金羽 GB826、安全舱2号 E5011、ORSA D850、飞羽 Plus D6017。
  - 🥈 **第二档 · 价格合适值得买**：蜂鸟 C826/C828、Swan Youth GB828、POCKIT 3S/3H、安全舱 Pro E6011 等。
  - 🥉 **第三档 · 极低价才考虑**：蜂鸟 D829、POCKIT 2S、经典老高景观 GB08 等。
- **官方宣传与卖点文案**：点击卡片呼出弹窗，查阅设计哲学与文案亮点。
- **估价体系**：每款车型提供「闲鱼合理入手价」与「超过多少钱就不值」的明确价格锚点。
- **一键联动车源**：点击弹窗按钮，一秒跳转到 Tab 2 筛选出当前长沙在售的该型号现车。

### 🌊 Tab 2：闲鱼车源瀑布流 (21 条长沙精选在售车源)
- **多列响应式瀑布流**：适配手机、平板与 PC 宽屏，自适应流式排版。
- **真实实拍照片**：对接阿里 CDN WebP 优质实拍图，防裂图智能降级。
- **多维筛选与实时排序**：
  - 支持按车系筛选（GB826、E5011、C826、口袋车等）；
  - 支持按长沙区域筛选（雨花区、天心区、岳麓区、开福区、望城区、芙蓉区）；
  - 支持按推荐优先级筛选（🌟优先看、👍可考虑、💬议价备选、🔍待核实、⚠️不优先）；
  - 支持按挂牌价格从低到高、从高到低排序；
  - 关键词毫秒级即时模糊检索。
- **车源详情弹窗**：
  - 挂牌售价对比专柜原价与节省金额；
  - 卖家完整自述与车况描述；
  - **独家实战验车与砍价建议**（针对每辆车的成色、车龄与结构做专业分析）；
  - **一键直达闲鱼**：点击专属高对比度按钮，在新标签页跳转对应商品页面 `https://www.goofish.com/item?id=...`；
  - 复制闲鱼链接便捷工具。

### 🛡️ 辅助防护工具
- **避坑黑榜**：展示已主动排查排除的 6+ 辆存在卡扣断裂、虚标引流、价格虚高等缺陷的负面典型。
- **现场验车清单**：汇总碳纤维管接头、折叠锁止、避震刹车与织物卫生 4 大步面交验车速查口诀。
