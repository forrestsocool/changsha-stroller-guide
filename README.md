## 💡 甄选口径与核心方法论

在二手母婴大件市场，盲目挑选几百元的低端入门货不仅不划算，更容易埋下严重隐患：
- **推车方面**：新车成交价低于 ¥1000 的入门杂牌及低端车耐磨度差、旷量严重、轴承生锈且无避震；
- **婴儿床方面**：严拒低端密度板/胶水多层板释放甲醛、非标护栏间距（>6.5cm 存在卡头窒息危险）、以及掉落式活动侧栏事故隐患。

本指南严格**剔除千元以下低端品类**，只锁定大厂研发成本高、用料扎实、但**二手折价率极大**的中高端标杆平台：

### 🍼 好孩子/gb 婴儿推车平台 (15款经典车型 · 21辆长沙车源)
1. **Swan 金羽系列 (GB826 / GB827 / GB828)**：高景观罕见的 7.2kg 纯碳纤维车架与 ARS 四轮万向同步转向。
2. **安全舱体系 (E5011 / ORSA Flip / E6011)**：40cm 豪华超宽座舱、单手收车与精密 8 轴承系统。
3. **ORSA 系列 (D850 / C4017)**：重量与推行最均衡的 6.8kg 黄金标杆。
4. **飞羽系列 (D5000 / 飞羽 Plus D6017)**：全碳纤维极限羽量与大角度平躺出行。
5. **蜂鸟系列 (C826 / C828 / D829)**：约 5.6kg 超轻兼顾双向推杆与新生儿平躺的高性价比神车。
6. **POCKIT 口袋车系列 (3S / 3H / 3Q / 2S)**：登机免托运与超微收折的差旅首选。

### 🛏️ 中高端全实木婴儿床平台 (12款经典床型 · 20张长沙好床)
1. **Stokke Sleepi 椭圆蛋形床**：欧洲进口山毛榉曲木，多阶可调节、颜值天花板。
2. **Boori 经典英伦实木床 (Classic/Pemberley)**：澳洲进口南洋杉，婴儿级无毒漆与超高自重稳定性。
3. **好孩子 gb 实木拼接大床 (MC828 / MC826 / MC830)**：无漆新西兰松，大床无缝拼接与摇篮储物多功能。
4. **蒂爱 DiiDee 德国进口榉木床**：硬度极高防啃咬、无漆环保物理打磨。
5. **棒棒猪 BBZ 榉木大床**：高承重母子同睡、大护栏高安全冗余。
6. **小龙哈彼 LMY618、芙儿优 ForU、葛莱 Graco、宜家 GULLIVER/SNIGLAR** 等高保有量耐用实木平台。

## 📱 移动端与客户端深度优化

1. **移动端高密度展示**：针对 iPhone 11 / 12 / 13 等常见手机屏幕，打破传统单列长滚动，采用精美 **2 列高密度流式布局**，一屏同时展示 4~6 件好物。
2. **闲鱼客户端原生唤端**：
   - 移动端点击「打开闲鱼看床/看车」时，优先通过 `fleamarket://itemDetail?itemId=...` 调起闲鱼 App；
   - Android 浏览器支持完整 Intent 协议并附带 H5 回退；
   - PC 端或无 App 环境下无缝 fallback 到闲鱼网页版，兼顾全端流畅体验。
3. **面交验货指导与避坑黑榜**：每款大件均配有现场验货 4 步法及剔除的踩坑负面典型列表。

## 🛠️ 运维与部署说明

- **Nginx 反向代理配置**：服务器 (`ubuntu@tjsj.sensen.li`) 监听 `8043` 端口（上游 SNI 分流），直接配置通配符证书 `/etc/certs/sensen.li/`，分别反代至 GitHub Pages 项目路径。
- **Cloudflare DNS**：`stroller.sensen.li` 与 `crib.sensen.li` 均解析至 VPS 公网 IP。
